# AutoClicker v1.0.3

- Uygulama sürümü sağ alt köşede gösterilir.
- Önceki sürümde kalmış eski fotoğraf ayarı tespit edilip temizlenir; varsayılan siyah arka plan gösterilir.
- Diğer kullanıcıların kendi seçtikleri arka planlar korunur ve uygulama içinden görsel seçmeye devam edebilirler.
- Açılışta onaylı, SHA-256 doğrulamalı tek EXE güncellemesi sürer.

İndirme için yalnızca `AutoClicker.exe` gerekir. Güncelleme sorusu çıkarsa **Evet** seçin; uygulama güncellenip yeniden açılacaktır.
